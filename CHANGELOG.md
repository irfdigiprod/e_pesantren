# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-13

### Added
- Initial project structure for e-Pesantren.
- Backend API using Bun, Hono, and Drizzle ORM.
- Frontend application using Vue 3 and Vite.
- Student management system with profile and behavioral tracking.
- Clinic and medical record management.
- Dormitory (Rooms) management.
- PDF and Excel export capabilities.
- Docker orchestration for easy deployment.
- Initial documentation: README, LICENSE, CITATION.cff, and CHANGELOG.
